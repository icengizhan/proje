# Secure Notes

Secure full-stack note-taking app.

## Architecture

* **Frontend:** React (Vite, Tailwind, TypeScript)
* **Backend:** NestJS (TypeScript, TypeORM)
* **Database:** MySQL
* **Cache:** Redis

## Setup

1. Clone repo.
2. Setup `.env` files in `secure-notes-backend` and `secure-notes-frontend`.
3. Start Docker.

## Docker Command

```bash
docker-compose up -d --build
```
